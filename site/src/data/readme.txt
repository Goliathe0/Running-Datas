📁 data/

→ Tes données locales (souvent temporaires ou statiques).

Exemples :

data/
├── activities.json
├── user.json
└── config.js


C’est pratique pour :

Stocker des exemples pendant le développement

Charger des fichiers JSON au lieu d’appeler une vraie API

Configurer des constantes globales (config.js)
